# Catálogo de jornadas — GamerTrust

Jornadas ponta a ponta para agents de produto, QA, personas e E2E (web Playwright + nativos iOS/Android). Paths de implementação vivem em cada app; aqui fica o contrato de produto.

Consumidores: `agt-persona-simulator`, `agt-ui-ux-auditor`, `agt-web-qa` (e equivalentes nos kits nativos).

## Formato padrão

```md
# <Nome da jornada>

## Objetivo
## Precondições
## Passos
## Estados esperados
## Erros possíveis
## Analytics
## Personas relevantes
## Critérios críticos
## Paridade visual
```
